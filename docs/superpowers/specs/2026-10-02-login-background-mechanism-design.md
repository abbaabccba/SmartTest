# 登录背景与动画接入规则

本规则用于后续登录背景扩展：不同背景的主体视觉大小相近，亮暗主题成对适配，图片与动画始终对齐，刷新不重新随机。保持现有登录表单与认证行为不变。本次仅记录规则，不修改运行代码、不新增背景。

## 当前实现

- `web/frontend/src/login-background.js` 是背景选择与挂载入口；列表目前只有 `pcb`，挂载逻辑仍专用于 PCB，尚未完成通用多背景接入。
- 首次随机选择 ID，保存在 `sessionStorage` 的 `smarttest.login.background`；有效选择在刷新时复用。已保存 ID 不在列表时重新选择。存储不可用时无法保证跨刷新保持选择，当前代码不会阻止页面显示。
- PCB 已有亮暗图片与对应路径、隐藏页面暂停，以及 CSS 减少动态效果适配；尚无统一的多背景销毁接口。
- 当前 PCB 共用坐标范围为 `1120 × 942`，白图 `1120 × 941`，暗图 `1120 × 942`；素材与路径一起缩放，尺寸上限避免继续放大原图。

## 背景选择

1. 沿用现有选择入口和存储键，不增加另一套随机或持久化机制。
2. 没有有效已存选择时，从已登记背景中随机选一套；同一标签页刷新不换，不自动轮播。
3. 这是浏览器标签页会话的展示状态，不是账号偏好；不保证不同用户、不同标签页一定选到不同背景。浏览器复制或恢复标签页可能继承会话状态，不承诺每次新开页面必换背景。
4. 亮暗切换只切换当前背景的主题版本，不重新随机背景 ID。

## 登记与职责

每套背景登记唯一 ID、亮暗素材、素材坐标范围、主体可见范围及自己的动画挂载实现。尺寸信息取自实际素材，不为凑统一文件大小拉伸图片。

现有登录背景入口负责选择、公共展示容器及主题和生命周期协调；每套效果只负责自身图像和动画内容。复用现有主题事件和 CSS 主题变量，不引入新的主题状态、认证状态或后台接口。先满足实际新增背景，不建设通用动画引擎，不为尚未确定的效果增加依赖。

## 尺寸与布局

1. 所有背景使用同一个左侧展示区域，右侧登录框的位置、尺寸和交互不因背景变化而改变。
2. 以当前 PCB 在同一视口下的主体可见范围为视觉基准。比较主体实际占用面积和高度，而非包含透明留白的文件宽度；不同长宽比按比例适配，不强行拉伸成同一比例。
3. 保留现有素材不放大的原则。新素材若清晰度不足以达到目标大小，先报告素材限制，不静默放大或牺牲清晰度。
4. 未定制的页面底色沿用主题 token；透明区域不自带矩形底色，不形成色差边界。
5. 素材裁剪必须明确方向和范围。只裁右侧留白时保持左侧原点、纵向范围和保留区域像素不变；若改变坐标原点，必须同步修改动画坐标并重新验证。
6. 沿用现有响应式布局边界；窄屏不因新增背景遮挡输入框、按钮或主题开关。

## 动画与主题

1. 图片和动画放在同一坐标容器中，共用缩放、定位和裁切变换；禁止分别计算导致错位。
2. PCB 信号沿可见电路线运动，终点与引脚或线路节点对应。其他背景使用适合其内容的动画，不机械套用 PCB 路径。
3. 每套背景提供亮暗适配；两版素材几何不一致时分别校准路径，不假设同一组路径天然适用。
4. 动画点击穿透，不影响登录操作。隐藏页面暂停，恢复可见时恢复；遵循减少动态效果偏好。
5. 背景卸载时清理它注册的监听、观察器、定时器和动画调度；重复挂载不叠加实例。暂停和销毁由公共入口协调，各效果完成自身资源清理。
6. 素材加载或绘制错误如实暴露，不用无关图片或额外特效静默掩盖。

## 后续执行清单

以下是后续机制实现与接入的清单，不代表本次已实现。

- 在现有入口上补齐背景登记、公共容器和生命周期契约，保留 PCB 现有效果与随机选择语义。
- 将 PCB 接入该契约，验证改造前后视觉一致；不同时重绘素材或调整脉冲风格。
- 每次新增背景先确认具体视觉方案，再提供亮暗素材、主体范围和动画实现。
- 保留覆盖选择稳定性、主题切换、尺寸联动、暂停恢复和销毁的重要行为测试；运行前端测试、lint、构建和 `git diff --check`。
- Chrome 实页验收记录视口与 DPR；在相同视口下比较各背景主体大小，检查亮暗切换、刷新、窄屏、动画对齐和登录交互。测试与构建不能替代实页视觉验收，无法连接浏览器时明确报告未验证项。

## 本轮边界

仅新增本规则文档。通用接入机制仍待实现，其他登录动画的内容与风格尚未定义；不增加背景切换按钮、不轮播、不调整登录业务、不提交或推送代码。

## 共享地球仪扩展设计

以下为后续地球仪开发范围，取代仅针对地球仪的“独立登录页效果”设想，尚未实现。

### 唯一实现与展示窗口

最新展示调整：Coco 已将登录页的完整球体改为放大局部展示。登录 framing 固定倾斜 23.5°，视角纬度在南北 60°之间平滑往返（约 4 分钟一轮），继续原有经度自转；仅改展示参数，不改地点、连线或数据。Global Operator 的现有 framing 保持原样。下文完整球体描述为此前方案，以本段为准。

复用 `global-globe.js` 的 `createGlobalGlobe`、`globalLocations` 及已有 `d3-geo`；不复制登录专用绘制逻辑。Global Operator 与登录页共用数据、主题、旋转、边界、标注和连线逻辑。差异仅是展示窗口的尺寸、球体位置与裁切：前者保留现有局部展示布局，后者完整显示球体，主体大小与 PCB 接近。

Canvas 按实际显示尺寸和 DPR 绘制。沿用 `product-line-motion.js` 现有调度与可见性生命周期能力，具体接入在实现前核对，避免增加平行调度 owner。登录选择列表增加地球仪，原 PCB 与已存选择不变。

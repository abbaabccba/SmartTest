# Jira / Project 卡片数据明细浮层

## 已确认目标

Coco 已确认交互样例的布局：点击卡片数字或图表数据，打开明细浮层；显示范围、统计值、表格、更新时间和分页，支持关闭按钮、Esc、关闭后焦点恢复。所有 Jira / Project 数据卡片同步适配，Comments 和 Verify 排除。仅增加明细展示，其他行为不变。

## 范围

- Jira 页面与 Dashboard 的 Self-Test、Task、Customer Feedback 卡片：Bugs / Tasks / Component/s / Invalid，包括本期、上期、产品线及人员或组件维度。
- Projects 页面项目数量、Block / Warning、角色资源、Support Mode、平均分配数及产品线/阶段数据汇总；Project Resource Statistics 的角色、人员分配数据。
- 已有 Project Release Dashboard 中项目/版本、健康状态、关联 issue 数量及关联 Jira 数据展示。
- 不改变统计口径、筛选规则、权限、刷新调度、数据存储归属、导航及现有业务动作；不增加远端刷新或 Comments / Verify 原文存储。后续已授权 Download：仅导出本次浮层固定展示的全部记录和现有列，不新增服务端导出或远端读取。

## 展示及风格

- 复用项目现有浮层/对话框能力（若有）、按钮、表格、分页、状态语义和主题 token，不引入 UI 库，不照搬样例独立色值。
- 统一浮层外框：顶部业务标题、点击对应的已应用范围、统计值；主体明细表；底部已有数据更新时间（没有则明确不可用）与分页。
- Jira 列按现有字段显示 key、标题、状态、相关人员等；项目列显示项目、产品线、阶段、状态、支持模式等；分配统计一行表示项目—角色—人员关系。
- 比例显示分子、分母及各自记录范围；平均值展示原计算的分配记录与人数依据，不改变去重规则。
- 有效点击入口覆盖数字和图表数据，维度切换控件保持原用途。仅一个浮层。小屏表格允许横向滚动，浮层适应屏幕。
- 关闭保持页面滚动及卡片状态；支持键盘访问和焦点管理。Project 名称、Jira key 与标题使用原 owner URL 在新窗口/标签打开，无 URL 保持普通文本。
- header 的 Download 复用现有按钮与图标；ExcelJS 按需加载，导出全部记录为 XLSX，附带标题、范围和数据更新时间。下载防重复；失败在浮层提示，关闭或切换浮层后不保存迟到结果。
- 浮层固定居中，使用原生 dialog 背景遮罩；导航与其他浮层通过共享 glass/overlay token 消费模糊效果，减少透明度时禁用。

## 查询与封装

- 前端统一明细浮层展示 owner，各卡片只传业务范围与列定义，不复制业务统计机制。
- 现有响应已包含完整明细时直接复用；缺少明细时由原业务 owner 提供只读查询出口，复用现有权限、查询快照与过滤逻辑。不能由前端提交任意权威 ID 集合或任意 SQL。
- 点击使用当时展示结果对应的版本和范围，包括 card_key、指标、产品线、周期、本期/上期、人员/组件或项目分配维度；实际参数命名由已有接口决定。
- Jira 复用 jira_analytics_queries / jira_analytics_snapshots / jira_analytics_facts 的当前统计来源及原聚合逻辑；需要基础字段时通过已有 issue owner 读取。不得把当前可变基础字段误称为历史快照字段。
- Project / Release 复用现有查询 owner 和数据库快照。已加载结果与后端分页必须明确完整性，不能以局部页面冒充完整明细。
- 打开浮层不启动远端请求、不刷新统计、不创建新的持久 owner。快照不可用或权限不足时明确展示失败，不退到全量或其他版本。
- 浮层打开后固定本次点击范围；异步响应不得串入已关闭或新打开的浮层。销毁页面时清理事件与待完成展示。

## 验收

- 所有范围内可统计数据能查看与当前已应用条件相符的明细，Comments / Verify 不接入。
- 表格记录总数或贡献合计与原统计口径一致，比例/平均值可追溯计算依据。
- 打开、关闭、分页不改变原筛选、刷新、调度、业务动作或其他功能。
- 使用现有风格体系，明暗主题可读；错误如实显示，无新增依赖或无关重构。
- 所有受影响验证通过，临时诊断与失败尝试清理，git diff --check 通过。

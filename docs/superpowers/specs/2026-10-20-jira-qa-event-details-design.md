# Comments / Verify 数据明细展示（第二阶段）

## 目标

复用已有数据明细浮层、Apple 风格体系和 Download，让用户查看第一阶段存入 MySQL 的 QA 原始动作。继续监测正在运行的唯一采集批次，不重触发采集，不在开发中重启或干扰其进程。

- Comments：按 Jira、QA 人员展示评论数量和 QA 上传数量；展开后按时间列出评论正文、文件/图片名称和上传时间。
- Verify：展示 QA 的全部符合既有 Verify 定义的历史，包含操作人、时间、前后状态。
- 计数口径、QA 身份、已应用查询、周期、刷新权限和调度不变；打开、展开、翻页、下载均只读数据库。

## 布局与交互

沿用 `createDataDetails()` 和 `.data-details`，保持居中、背景模糊、公共主题 token、Close/Esc/焦点恢复。

1. 顶部保留指标名称、人员、产品线、周期、本期/上期、卡片统计值、数据时间和 Download。
2. 主列表一行一个 Jira—QA 人员关系：Jira Key、标题、人员、评论条数/上传数或 Verify 历史条数、最近动作时间。Jira Key/标题沿用原 URL 在新标签打开。
3. 行内展开后显示该 Jira/人员的动作列表，不叠加第二个浮层；动作时间默认从新到旧，分页使用原浮层 25 条规则。
4. Comments 动作列显示类型、作者、原时间、正文或文件名。评论保留换行；附件仅名称、原上传时间及已有元信息，不加载文件、图片或缩略图，也不根据正文猜附件关联。
5. Verify 动作列显示作者、原时间、变更前状态、变更后状态。顶部明确区分“卡片计数（最后一次贡献）”与“完整 QA 历史条数”，不能声称两数应相等。
6. Comments 汇总数量不混入附件数；评论和上传动作分别标示。没有动作时间则显示不可用，不制造时间。
7. 正文首期安全文本展示：字符串原样显示，结构化正文通过可维护的现有文本能力展示；无法直接文本化时如实显示结构化内容，不插入未经处理的 HTML、不预取远端图片，原始内容保留在导出中。

## 零计数和未分配 QA 的可达性（拟议）

现有排行会隐藏两期均为零的人员，且无产品线归属的 QA 没有排行行。仅给柱形加点击会漏掉这部分历史。

- 保持原排行和产品线切换不变。
- Comments / Verify 指标提供一个轻量 `Details` 入口，查看当前产品线、周期的全部 QA 明细，包括卡片计数为零但存在历史的人。
- 浮层提供明确标记的“全部 QA（含未分配）”范围入口，仍限制在当前卡片已应用 JQL 和周期内；人员归属沿用证据采集时记录，未分配标明未分配，不推断产品线。
- 点个人柱形时默认只看被点击人员及产品线；切换全部范围必须由用户显式操作，标题同步说明。

## 数据 owner 与版本

- 后端扩展 `JiraAnalyticsRepository` 及现有卡片认证路由；前端扩展 `createJiraStatisticsCardApi()`。不走可能触发远端详情任务的通用 issue details 入口。
- 原 statistics owner 在同一次来源解析中提供小型证据引用，包含 base snapshot、实际 metric source snapshot、roster/格式版本和显示范围；这些只是版本标识，不能代替后端授权。
- 每次明细请求验证当前认证账号、卡片、有效 base、来源引用及证据 `complete/version/roster`。禁止客户端传任意 issue ID 集合扩大范围。
- 卡片版本已变时明确提示重新打开；旧快照未采集、来源未完成、失败来源不能当作零条，也不能回退其他版本或查询远端。
- 周期沿用原 issue.created 切片，不改成按评论或 Verify 的动作时间筛选；跨年周期解析实际涉及的年度来源，不能只读一个年份。
- 产品线按来源捕获的 QA roster 归属筛选；Verify 不按 person.verifyCount > 0 筛候选，确保最后操作是非 QA 时仍能看到此前 QA 历史。
- Jira 标题/状态等基础字段可能来自当前缓存，应延续现浮层说明，不能称为原动作发生时的历史字段。

## 查询、分页和下载

- 复用 MySQL 证据表和现有快照 owner，不增加存储、缓存或调度机制。
- 卡片首屏和 Redis 统计缓存不携带评论正文。首次打开只读轻量汇总；展开动作行时才读取正文页。
- 时间保留原值展示，排序使用既有 ISO 解析能力统一到 UTC，原生 ID 作稳定次序；不可按不同偏移的时间字符串直接排序。
- Download 主动点击后，在同一组服务端确认的版本引用内分页读取所选明细的完整记录，复用 ExcelJS/下载 owner，不能只导出当前页。途中版本变更明确失败，不拼接不同版本数据。
- 下载包含 Jira、人员、动作类型、原时间、评论原文/文件名称/状态变化及范围说明；不下载附件本体。
- 复用原异步生命周期：关闭、换范围或销毁时，旧响应不得写进新浮层；关闭后不保存迟到的下载结果。
